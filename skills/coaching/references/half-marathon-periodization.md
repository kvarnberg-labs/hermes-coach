# Half-marathon periodisation (long horizon)

Load when planning or reviewing a runner's build towards a half marathon (or
similar 10K–HM goal) over several months.

## Goal anchor (never inflate)

- The athlete's stated goal is a persistent anchor: retrieve it from saved
  memory and the conversation; if it is not there, say so and ask. Never
  invent, upgrade or "round" it (a recorded "under 1:40" never becomes
  "sub-1:38"). Goal inflation is fabrication and shifts every prescription.
- Once confirmed, do not ask again; acknowledge it briefly and plan. If the
  athlete says this discussion keeps repeating, stop the loop: restate the
  known goal and constraints and give the concrete next step.
- A new or revised goal stated by the athlete → save it to memory at once.
- Never promise perfect recall: say what is saved, use fresh intervals.icu
  data, say when a detail is missing.

## Weekly adjustment loop (planned → actual → decide)

Review each week: actual vs planned run count, duration, distance,
session-RPE/load, long-run duration, quality completion; CTL/ATL/TSB, ramp
rate, HRV, sleep, resting HR, breathing symptoms.

- **Hold** when fatigue or breathlessness worsens, resting HR stays elevated,
  HRV is suppressed, or quality degrades.
- **Reduce + recover** when several signals agree.
- **Progress one variable** (usually duration before pace) when recovery is
  stable.
- Reassess the phase every 3–4 weeks; one bad run does not change the plan.
- Decide on load, recovery markers and breathing — not pace alone.

## Plan quality

A useful plan states the causal hypothesis it tests (e.g. reduce accumulated
fatigue while keeping one controlled quality stimulus), a short initial block
with exact weekly structure, and the observation that will trigger progression
or reduction. A generic phase outline is not an answer to "what do you think?".
Recent TSB/ATL can support current fatigue but cannot explain a decline that
began years earlier. If the athlete asks whether the plan has a purpose, link
every component to the goal (easy = aerobic base, quality = threshold/speed,
long run = durability, strength = economy/resilience, recovery = adaptation).

## Starting point

Do not prescribe goal pace as everyday pace when current data is clearly
slower. A typical start (e.g. ~35 km/week, CTL ~29, 10K ~53 min, 16 km long
run): 3 runs/week — two easy, one controlled quality — plus 1–2 short strength
sessions, long run at the weekend. Add a fourth run and build towards
40–50 km/week and an 18–22 km long run only when recovery and breathing
tolerate it. Deload every 3rd–4th week. Weekday availability of ~60 min is a
hard limit for every weekday session, including combined run + strength.
Breathlessness at modest pace: `references/running-plateau-and-breathlessness.md`.

## Paces

Goal pace = goal time / 21.1 (1:40 → 4:44/km). Threshold pace (≈ 60-min race
pace) is typically 10–15 s/km faster than HM pace — never set the target pace
as threshold pace. Threshold sources and pace zones:
`references/norwegian-singles.md`. Without any threshold data, use HR: easy
< 85 % LTHR, threshold 95–100 % LTHR.

## Phases (10-month example, 5–6 days/week)

| Phase | Months | Running | Strength |
|---|---|---|---|
| 1 Base + strength | 1–4 | 3–4 easy 35–50 min Z1; 2 threshold from 1×4 → 2×8 (`norwegian-singles.md` progression); long run 60 → 90 min Z1–Z2; deload every 3rd–4th week (−30–40 % volume) | 2×/week compound lifts: anatomical adaptation → max strength → power |
| 2 Intensification | 5–8 | 3 easy 40–50 min; threshold 2×8 → 2×10, third weekly session if not a beginner; long run 90–120 min, last 20 min moderate; 2–3×5 min at HM pace in long runs from month 7 | 1–2×/week maintenance |
| 3 HM-specific | 9–10 | 2–3 easy; 1–2 threshold; long run with 10–20 min HM-pace blocks; 10K/HM B-race in month 9 | 1×/week; no heavy legs in the last 10 days |
| 4 Taper | last 10–14 days | D-14…10 last long run at 50 %; D-9…7 short threshold 2×5; D-6…4 easy + 3–4×60 s HM pace; D-3 easy 30 or rest; D-2 rest/20 min jog; D-1 rest, strides optional | — |

Race-day TSB target +5 to +15. Heavy leg strength never the day before a
threshold run. Strength A/B for runners: `references/strength-for-runners.md`;
strength programming itself belongs to the `strength-coaching` skill. Early
strength: two controlled sets at RPE 6–7, three only after stable tolerance. A
15–25 min easy cross-trainer block (RPE 3–4) can add aerobic volume next to
short strength, never replacing the key run.

## Pitfalls

- Long runs are mostly Z1–Z2; HM-pace blocks arrive gradually in phase 3.
- Keep strength — it supports economy, injury resistance and bone density.
- Ten months is plenty; consistent weeks beat crammed volume.
- Female athletes: cycle phase can affect RPE and recovery
  (`get_coaching_knowledge("female physiology")`); heavy menstrual bleeding
  raises iron-deficiency risk.
- Rest days are named in the plan table, not created as events; show the plan
  for approval before any calendar write (`references/training-plan-creation.md`).
