# Zwift workout search and post-ride analysis notes

## Search and recommendation
- Distinguish the Zwift in-game workout library from the Zwift product store.
- Verify a named workout against an official/current source before recommending it. If official verification is unavailable, state that limitation and provide the interval structure to recreate rather than asserting a title.
- For a same-day hard workout, check recent load/wellness and ask how the athlete feels; positive TSB alone is not sufficient.
- When translating targets, identify which FTP the workout uses. Configured FTP controls Zwift/intervals.icu percentages; compare it with eFTP and flag gaps over 10 W.

## Post-ride review
1. Find the newest activity with a 3-day Ride query if a 1-day query may miss sync lag.
2. Pull activity detail for interval summary, power/HR zones, variability index, and decoupling.
3. Pull wellness and sport settings before interpreting IF or zone distribution.
4. Compare configured FTP versus eFTP before judging intensity; do not infer FTP from a routine, non-maximal workout.
5. For threshold sessions, distinguish actual work intervals from whole-session averages. Report whether the intervals were threshold, sweet spot, or tempo relative to the correct FTP.
6. Treat high decoupling as a contextual signal (heat, fatigue, pacing, hydration), not an FTP estimator.
