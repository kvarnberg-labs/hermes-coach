# Strength Training for Runners

## Why runners need more than legs

Runners who only do lower-body strength (squats, deadlifts, lunges, hip thrusts) miss three critical areas:

| Area | Why it matters | Example exercises |
|---|---|---|
| **Upper body** | Arm drive efficiency, posture late in race | Rows, overhead press, push-ups |
| **Core/anti-rotation** | Form under fatigue, power transfer | Pallof press, dead bugs, plank variations |
| **Plyometrics/spänst** | Running economy, elastic recoil | Box jumps, single-leg hops, pogo jumps |

## Programming pattern: 2×25 min beats 1×45 min

For time-crunched athletes who run 5-6 days/week, two short strength sessions work better than one long one:

- **Session A (legs):** ~25 min, paired with an easy run day (Monday)
- **Session B (upper body + core + plyo):** ~25 min, on a non-running day or easy day (Friday)

Rotate exercises between weeks within each category to prevent staleness and overuse.

## Session templates

### Session A — Legs (~25 min, 60s rest)

Pick 3-4 from:
- Bulgarian split squat — 3×8/leg
- Romanian deadlift — 3×10
- Hip thrust (weighted) — 3×12
- Walking lunges — 2×12/leg
- Goblet squat — 3×10
- Single-leg deadlift — 3×10/leg
- Lateral lunges — 2×10/side
- Explosive hip thrusts — 3×10

### Session B — Upper body + core + plyo (~25 min, 45-60s rest, superset where possible)

**Upper (pick 2):**
- Dumbbell row — 3×10/side
- Overhead press — 3×8
- Push-ups — 3×max
- Single-arm row — 3×10/side
- Clap push-ups — 3×8

**Core (pick 2):**
- Pallof press — 3×10/side
- Dead bugs — 3×12/side
- Plank with shoulder taps — 3×30s
- Side plank with rotation — 3×10/side

**Plyo (pick 1):**
- Box jumps — 3×6 (soft landing)
- Single-leg hops — 3×8/leg (focus on rebound)

## Scheduling constraints

- No weekday combined sessions over 60 min (run + strength)
- Strength A (legs) on Monday is acceptable if the run is easy (~35 min) and strength is capped at 25 min = ~60 min total
- Strength B (upper body) can go the day before a threshold session — it won't compromise leg freshness
- Never do heavy leg strength within 48h before a threshold session
- Saturday threshold + Sunday long run is standard Norwegian Singles weekend loading

## Pitfalls

- **Only prescribing legs** is the #1 strength programming error for runners. The athlete will notice and call it out.
- **Identical sessions every time** — 4× the same 4 exercises is lazy programming. Rotate.
- **Missing plyometrics** — runners specifically ask for "spänst" and it directly improves running economy.
- **Rest days must be explicitly labeled** — a blank calendar day is not a rest day to the athlete. Name them "🛌 Vilodag".
